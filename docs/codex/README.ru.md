# Конфигурация Codex

[English](README.md)

Источник — приватный submodule `home/dot_codex`; назначение — `~/.codex`.
Модель и reasoning выбираются в Codex и сохраняются при применении.
Нативные настройки MCP находятся в `home/dot_codex/config.base.toml.tmpl`.
Зависимости устанавливает `home/dot_config/mise/config.toml`.

Глобальный AGENTS содержит личные правила. Семь skills и четыре роли используют
инструменты Codex; импортёров Claude и обязательного superpowers-процесса нет.
Системные skills и плагины приложения OpenAI сохраняются.

## Окружение и хуки

`shell_environment_policy` наследует окружение процесса и явно задаёт переменные
из `home/.chezmoitemplates/session-env.tmpl`, включая OPENROUTER_API_KEY.
Шаблон общий с Fish, Zsh и launchd; секреты подставляет KeePassXC при применении.
Результат хранится в приватном config.toml. Модификатор передаёт Python-код и
данные в base64, чтобы shell не интерпретировал содержимое.

Принудительного Fish нет. Для проектных версий инструментов — `mise exec -- <команда>`.
В хуках остаются проверки точных npm/pnpm-зависимостей, массового завершения
процессов, AI-футеров и тега Kaiten. `Bash` — штатное имя shell-события Codex,
включая exec_command; это не адаптер Claude.
Хуки не подменяют команды, не вызывают thinks, не запускают автоформатирование
и не добавляют напоминания после каждого редактирования.

## Возможности по задаче

Serena и thinks отключены по умолчанию. Context7, Things, Nanobanana, Veo и
Peeshet сохранены. Серверы, добавленные приложением или пользователем вне этого
списка, модификатор не удаляет.

Claude-плагины отключаются; их marketplace удаляется из конфигурации Codex.
Импортированные synced-skills и 30 сторонних дизайн-skills отключаются штатными
`skills.config`. Их файлы и конфигурация Claude остаются на месте.

MCP можно включить отдельно в доверенном проекте:

```toml
# .codex/config.toml
[mcp_servers.serena]
enabled = true
```

Отключённый skill включается в пользовательском конфиге; проектные записи
`skills.config` Codex игнорирует. Измени существующую запись нужного skill:

```toml
# ~/.codex/config.toml
[[skills.config]]
path = "/Users/aimuzov/.agents/skills/design-review/SKILL.md"
enabled = true
```

Используй фактический абсолютный путь на своей машине. После изменения открой новый чат.
Повторный apply снова применяет управляемые отключения skills. Чтобы сохранить
выбор, измени соответствующее правило в исходниках. Проектные переопределения
MCP хранятся отдельно.

## Применение и проверка

Пользователь запускает `chezmoi apply`, затем открывает новый чат и подтверждает
изменённые хуки, если Codex запросит доверие. Агент не запускает apply/status/diff.
Удалённые установочные скрипты больше не запускаются; оставшиеся старые файлы
в домашнем каталоге не вызываются новой конфигурацией.

`python3 -m unittest discover -s home/dot_codex/tests -v` проверяет слияние,
сохранность настроек, отключения, защитные хуки, рендер шаблонов с фиктивными
секретами и идемпотентность. Подробности решения — [аудит](audit-2026-11-15.md).
