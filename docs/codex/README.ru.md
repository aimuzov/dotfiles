# Конфигурация Codex

[English](README.md)

Приватный `aimuzov/dotfiles-codex` подключён как `home/dot_codex`. Chezmoi разворачивает
его в `~/.codex`. На новой машине нужен доступ к приватным submodule.

Внутри: глобальный `AGENTS.md`, четыре агента, семь skills из личных команд Claude,
хуки и модификатор `config.toml`. MCP-серверы берутся из общего
`home/dot_claude/mcp.json.tmpl`; секреты подставляет KeePassXC. Serena использует контекст
`codex`. Для нового MCP по-прежнему нужны определение и установка пакета в mise.

Модификатор сохраняет выбранную модель, настройки приложения, неизвестные MCP-серверы,
плагины и хеши доверия. Управляемые серверы заменяются целиком. При изменении TOML
форматирование нормализуется; при повторном запуске файл не меняется.

`run_after_5_codex-skills` подключает личные skills в `~/.agents/skills` ссылками.
Существующий импорт `commit` сначала сохраняется в `~/.codex/backups/imported-skills`.
В импортированных synced-skills исправляются выдуманный домен Codex.ai и команда Codex -p;
исходные документы сохраняются в `~/.codex/backups/imported-skills-docs`.
Остальные app-owned skills не копируются в git. Их инструменты зависят от окружения;
например, import-memory требует доступного инструмента записи памяти.

`run_after_6_codex-plugins` устанавливает недостающие включённые плагины через официальный
`codex plugin add`. Кэш и подтверждения хуков не хранятся в git. Telegram из Claude не
переносится: эквивалент канала нужно подключать отдельно. Проектные плагины вроде Sentry
не включаются глобально.

Хуки проверяют точные npm/pnpm-зависимости, массовое завершение процессов, AI-футеры,
тег Kaiten и успешный thinks/check_as_me с оценкой от 90 в текущем ходе. После apply_patch
разбираются все пути, запускается локальный oxlint и добавляются напоминания. При старте
сессии общая память Serena подключается к ворктри.

После `chezmoi apply` открой новый чат Codex и подтверди обновлённые хуки в приложении.
Хеши доверия не подставляются автоматически. Режим plan и права выбираются в интерфейсе;
ограничения tools из Claude не превращаются в отдельный sandbox для агента.

Команды доступны как `$source-command-commit`, `$source-command-cr`,
`$source-command-comments`, `$source-command-typo`, `$source-command-new-site`,
`$source-command-release`, `$source-command-nested`. Старое написание `/cr` и подобное
описано в глобальных инструкциях как обращение к соответствующему skill.

Проверки скриптов: `python3 -m unittest discover -s home/dot_codex/tests -v`.
Сами настройки проверяются рендером шаблонов с фиктивными MCP без KeePassXC.
