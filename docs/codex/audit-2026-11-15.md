# Аудит конфигурации Codex

Задача: [dotfiles #34](https://github.com/aimuzov/dotfiles/issues/34).
Приоритет пользователя — лимиты подписки Codex при сохранении качества.
Изменения подготовлены в исходниках; применение выполняет пользователь.

## Вывод

Основной подтверждённый дефект — дополнительные обязательные процедуры и
перенесённые инструкции Claude. Само наличие большого файла skill не означает,
что весь файл загружается на каждом запросе. Поэтому считаем отдельно каталог
skills, прочитанные инструкции, вывод инструментов и повторную работу.
Размер исходников ниже — не измерение токенов и не процент экономии подписки.

## Окружение без Fish

Нативный Bash видел mise и утилиты из его installs, но не OPENROUTER_API_KEY.
Нативный Zsh видел ключ через .zshenv; дочерний Bash и mise exec наследовали его.
Значения секретов при проверке не выводились. launchctl в проверенном окружении
не вернул ключ, поэтому полагаться только на окружение GUI нельзя.

В новой конфигурации shell_environment_policy.set получает переменные из того же
шаблона, что Fish и Zsh. Это не требует новой копии секретов в исходниках.
Итоговый приватный config.toml содержит отрендеренные значения, как и MCP credentials.
Для версий инструментов конкретного проекта остаётся mise exec.
После пользовательского apply нужен smoke-тест в новом чате: наличие ключей без
вывода значений, пути утилит и простой вызов через Bash и mise exec.

## Проверки и ограничения

Пройдено 16 тестов unittest и валидация семи skills штатным quick_validate.py.
Git diff --check проходит в основном репозитории и приватном submodule.

Тесты покрывают сохранение настроек приложения и неизвестных MCP, отключение только
Claude-плагинов, сохранение посторонних настроек skills, идемпотентность, защитные
хуки и рендер реальными шаблонами chezmoi в изолированном каталоге с фиктивными секретами.
При рендере найдено повреждение Python-кода на пути через shell heredoc;
передача исходника и данных в base64 устранила его. Активный config.toml не менялся.

После первого пользовательского apply обнаружен пропущенный проектный модификатор
`home/Projects/r1/stv/webapp-next/dot_codex/modify_private_config.toml.tmpl`.
В нём устранена та же проблема передачи кода. Регрессионный тест воспроизводит
ошибку на старом шаблоне и проверяет новый шаблон, сохранение локальных настроек
и повторное применение. Проектный вызов использует `global_config=False`:
он обновляет только управляемый MCP, без глобальной миграции plugins и skills.

Сокращение глобального AGENTS примерно на 66%, инструкций ролей примерно на 91%
относится к байтам UTF-8. Роли загружаются по задаче; это не постоянная экономия
такого же процента на каждом запросе. Расход подписки зависит и от модели,
reasoning, размера задачи, вывода и инструментов. Цену API нельзя подставлять
в формулу расхода лимита подписки.

Для проверки эффекта сравнить несколько однотипных задач до и после в новых чатах,
при одинаковой модели, reasoning и скорости: результат, переделки, вызовы инструментов,
компактизации и доступный показатель расхода. Модель менять отдельным экспериментом.
Установленные системные инструкции приложения, текущая история чата и доступность
инструментов не сокращаются редактированием AGENTS задним числом.
