# Codex configuration

[Русская версия](README.ru.md)

The private `aimuzov/dotfiles-codex` submodule at `home/dot_codex` supplies `~/.codex`:
global instructions, four custom agents, seven command skills, hooks, and a config modifier.
MCP definitions come from `home/dot_claude/mcp.json.tmpl`; KeePassXC renders secrets during
apply. Serena uses its `codex` context. New MCP packages still belong in mise.

The modifier preserves the model, desktop settings, unrelated MCP servers, plugins, and
hook trust state. Managed server definitions are replaced in full. TOML is normalized only
when managed values change. No rendered secrets, auth files, sessions, or plugin caches
are tracked.

After apply, a script links command skills into `~/.agents/skills`, backing up imported
copies first. Another script repairs invalid Codex.ai links and Codex -p references in
imported synced skill documents, with backups. App-owned skills remain outside git and
still require the capabilities mentioned in their instructions.

Missing enabled Claude marketplace plugins are installed with `codex plugin add`.
The Telegram channel and project-specific Sentry enablement are not globally migrated.
Plugin hooks still require user trust; trust hashes are not generated by dotfiles.

The policy hook adapts dependency pinning, process-kill guards, Claude/Codex attribution
checks, Kaiten tags, and successful thinks checks scoped to the current session and turn.
Patch hooks handle multiple files and moves, run a project's own oxlint, and add reminders.
SessionStart links Serena worktree memory.

Run `chezmoi apply` yourself, open a new Codex chat, and review the updated hooks. Select
plan mode and permissions in the app. Custom agents inherit the parent's sandbox; their
tool lists are behavioral instructions rather than isolated permission boundaries.

Commands are skills named `source-command-{commit,cr,comments,typo,new-site,release,nested}`.
Invoke them from the skills menu or with `$source-command-<name>`.

Script checks: `python3 -m unittest discover -s home/dot_codex/tests -v`.
